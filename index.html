How It Works

Four-stage evolutionary loop with elitist selection and adaptive mutation

1

Initialize Population

Generate an initial population of agent configurations: system prompts, temperature, top-p, and reasoning strategies sampled from prior distributions.

pop_size=64, init=uniform
2

Evaluate Fitness

Run each agent variant against benchmark suites (MMLU, HumanEval, GSM8K, ARC, TruthfulQA) to compute a weighted composite fitness score.

eval=parallel, n_trials=3
3

Select & Mutate

Tournament selection picks top performers. Crossover blends high-fitness genomes. Adaptive mutation perturbs parameters and rewrites prompt segments via LLM.

select=tournament(k=5), mut_rate=0.15
4

Converge

Repeat until convergence or budget exhaustion. Track Pareto front across benchmarks. Export best agent configs for deployment.

max_gen=50, early_stop=5

Research

Key findings from evolutionary optimization experiments

Prompt Evolution Outperforms Manual Tuning

Evolutionary search over system prompts consistently discovers configurations that outperform expert-written prompts by 12-18% on composite benchmarks. The strongest gains come from non-obvious structural patterns in prompt phrasing that manual iteration rarely explores.

Manual baseline

68.4%

Evolved best

81.7%

Diminishing Returns After Generation 30

Fitness gains plateau significantly after ~30 generations across all benchmark suites. The optimal cost-performance tradeoff for most use cases is 25-35 generations, after which marginal improvements fall below 0.5% per generation.

Temperature Is the Highest-Leverage Parameter

Sensitivity analysis reveals temperature has 3.2x the effect size of any other continuous parameter. Optimal temperatures vary by task type: reasoning tasks converge to 0.1-0.3, creative tasks to 0.7-0.9.

Reasoning optimal

T = 0.18

Creative optimal

T = 0.82

Cross-Benchmark Transfer Is Limited

Agents evolved for one benchmark transfer poorly to others (avg -8.3% when evaluated out-of-distribution). Multi-objective evolution with Pareto selection produces more generalizable agents at a 4-6% cost to peak single-benchmark performance.
